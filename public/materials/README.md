# Material sources

Fabric041, ambientCG: https://ambientcg.com/view?id=Fabric041
License: CC0 (https://docs.ambientcg.com/license/).
Original 1K JPG material package retained in fabric/. The current SVG/CSS renderer uses the color texture with charcoal tint; normal, roughness and displacement maps are included for a future physically based renderer, not currently evaluated as PBR maps.
