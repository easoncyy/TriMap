# 知识观测站视觉集成

将已确认的本地预览接入 PR #10 合并后的 main。保留原知识模型、API、权限、草稿与发布流程；样例仍为 61 个知识节点、94 条关系，不因概览隐藏标签而删减知识。未改动数据库、部署配置或运行时依赖。

## 行为与实现

- 深色观测站界面、多层运动星云、椭圆轨道、共享 WebGL 棱锥材质及光云光标；浏览器不支持 WebGL 时保留图谱的矢量物体和交互。
- 星图自动布局采用倾斜椭圆及确定性非均匀分布。布局版本升级保留手动坐标、手动关系镜及目标预览，并备份旧探索状态。
- 光标位置直接响应指针；仅视觉尺寸随画布缩放。相机移动期间使用已绘制材质的变换，停止后刷新，降低缩放期间重绘负担。
- 标签使用有界避让、引导线和连续字号补偿；底部节点可在上方显示文字。稠密概览隐藏可选文字，保留选中、缩放、列表和完整知识索引。
- 点击棱锥可打开完整知识条目，查看依据和全部关联，并在图中定位。新增阅读弹窗延续深色材质。
- 暂停星光及系统减少动态效果受支持。字体职责见 [字体系统](typography.md)。

- `npm run typecheck` 通过；`npm test` 81 项通过。
- `npm run build` 通过；保留存储模块动态文件系统访问导致的两条构建追踪警告。
- `npm run test:integration` 通过，使用临时数据库验证迁移、访问隔离、反馈、个人发布、版本差异和原维护流程。
- `cloudflare/` 的 `npm test` 5 项通过、`npm run build` 通过。新增资源测试检查两个入口字体 CSS 一致、引用文件存在、单文件不超限。
- Chromium 检查平移、节点拖动、关系镜独立拖动、折叠展开、保存恢复探索、刷新保留位置、自动布局、色散／折射、列表、沉浸模式及维护者入口。
- WebKit 检查 1440、1024、390、320px，无页面水平溢出；三个生态节点文字可见。完整知识索引、LeRobot 六条关联、减少动态效果均已检查。

- Pages 构建静态文件通过 Chromium 烟测，API 代理本机临时测试实例。确认 [页面效果](screenshots/pages-1440.png)、知识索引、字体请求和减少动态效果；这不替代真实 Cloudflare 部署验收。

## 已知边界

WebKit 在初始化字体和尺寸变化时报告一次 `ResizeObserver loop completed with undelivered notifications.`；测试继续完成，未出现持续循环或操作失败。已保留在 [浏览器记录](browser-verification.json)，不将本轮结果描述为零浏览器警告。

自动化使用 WebKit/Chromium，未完成真实 Safari 设备、读屏器、低端 GPU 或公网冷启动性能验收。软件 GPU 的首次材质与标签收敛需要等待，截图在收敛后采集。本轮没有执行部署。

`public/optical/` 继承视觉实验的星空、星云与光云图像；动态材质和轨道逻辑在 `src/components/optical/`。保留完整字体许可，排除实验数据库、录屏、临时脚本和历史截图。下一轮视觉改动应同时验证 Next 与 Pages 入口，避免本地预览和发布构建之间的字体差异。
